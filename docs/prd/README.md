# Product Requirements Documents (PRDs)

This directory contains the PRDs that define features, architecture decisions, and milestones for `wrtpulse`.

## Naming Convention

Use zero-padded sequential numbers with kebab-case slugs:

```text
docs/prd/0001-core-collection-architecture.md
docs/prd/0002-dashboard-mvp.md
docs/prd/0003-alerting-engine.md
```

Copy [`TEMPLATE.md`](TEMPLATE.md) when starting a new PRD.

## Status Lifecycle

- **Draft** — Initial exploration and open questions
- **In Review** — Ready for design feedback and alignment
- **Approved** — Ready to implement
- **Implemented** — Shipped in the codebase
